# YTU Login：自动登录与安全修订

Android 8.0（API 26）以上的烟台大学 SRun 校园网认证客户端。运行时不依赖第三方网络或密码学库。

## 安装身份与旧版迁移

旧仓库公开了实际使用的调试签名私钥。这把密钥已不再适合保护应用更新；从源码删除文件不能让已经公开的密钥重新保密。

本修订正式版使用 `top.ytu.srunautologin.secure`，开发版额外带 `.dev`。两者可与旧版并存。新版不会读取旧包的私有数据，首次安装需要重新填写账号、密码、WiFi 和门户地址。先确认新版工作，再自行决定是否卸载旧版；不要为了迁移而清除旧版数据。

开发版由本机 `.local-signing/debug.keystore` 签名。正式版只接受外部私有签名配置，没有公开密钥兜底。不提供私钥下载，不把签名材料提交到仓库。同一安装身份的后续更新必须保留自己的签名密钥。

## 设置自动登录

1. 连接需要认证的校园 WiFi，打开系统位置信息开关，并授予应用精确位置权限。Android 12 以上只允许大致位置通常无法取得 SSID。
2. 保存账号和对应 WiFi，确认账号行处于勾选状态，然后启用自动登录。打开应用会恢复监测服务、WiFi 监听和周期任务。
3. 门户优先填写完整 HTTPS 地址，保留学校要求的端口。不要在门户配置中加入账号、密码、路径或查询参数。
4. 如果学校只提供 HTTP，填写完整 `http://` 地址，阅读并勾选未加密连接风险，再保存。目前系统网络安全配置只为 `202.194.116.116` 和 `172.16.0.1` 放行 HTTP；其他主机应使用 HTTPS，或由维护者明确审查并修改允许列表。
5. 如系统限制后台运行，请在系统设置中允许本应用自启动/后台运行，并保留监测通知。无需允许精确闹钟。

认证始终通过本轮锁定的 WiFi 直接连接门户。移动数据即使可用，也不作为认证的失败兜底。切换 WiFi、停止任务或修改配置会关闭相应连接。SSID 匹配不等于对接入点身份的密码学认证。

HTTP 兼容模式仍存在窃听和篡改风险：SRun 的 SRBX1 不是 TLS，观察到公开挑战值和登录参数的攻击者可能还原密码。本客户端无法修复学校 HTTP 门户本身的传输安全；不会自动忽略 HTTPS 证书错误或降级为 HTTP。

## 触发和重试

- 已保存 WiFi 可用、WiFi 互联网验证失效、用户启用自动登录、修改账号/门户/权限时安排检查；并保留系统允许的最短 15 分钟周期保底。
- 认证任务不要求预先通过互联网验证，否则未认证的校园 WiFi 上任务可能永远不启动。
- 同时到来的手动和后台认证会合并；同一调度 ID 的待执行任务会合并。
- 没有 SSID、没有绑定或网络不匹配时等待网络事件/周期检查，避免每 30 秒无限唤醒。
- 临时网络失败按有限指数退避重试。耗尽一轮后，后续周期任务可在冷却后开启新一轮。
- 密码拒绝、配置错误、TLS/重定向/过大响应等安全错误暂停自动重试，待用户检查配置；手动认证仍可用于排查。
- 已在线按成功目标处理，不继续重试。

周期任务和系统回调均不是精确计时器。强行停止应用、关闭系统位置服务、撤销精确位置权限以及厂商省电策略仍可能阻止后台认证。开机后如果系统尚未允许读取 SSID，先打开应用恢复监测。

## 构建

工具链：JDK 17、Gradle 8.13、Android Gradle Plugin 8.13.0、Kotlin 2.2.21、Android SDK 36 / Build Tools 36.0.0。Wrapper 发行包 SHA-256 固定在 `gradle-wrapper.properties`；Wrapper JAR 取自 Gradle 官方 8.13.0。

Windows：

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug assembleRelease
```

Linux/macOS：

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug assembleRelease
```

不提供私钥时 `assembleRelease` 只生成未签名正式包；开发包可直接安装。签名正式包需要四个环境变量：

- `SRUN_KEYSTORE_FILE`
- `SRUN_KEYSTORE_PASSWORD`
- `SRUN_KEY_ALIAS`
- `SRUN_KEY_PASSWORD`

不要把口令写在命令行、Gradle 文件或版本控制里。正式发布前在独立构建环境中通过私有密钥签名，并检查证书指纹。版本号默认固定，可用 `-PsrunVersionCode=<递增整数>` 覆盖；不再使用每次构建都会变化的当前时间。

CI 把单元测试和 lint 作为产出开发 APK 的必要条件。纯密码学参考向量继续保留；历史的源码字符串快照核对已由针对当前实现的安全/流程回归用例替代。

## 验证边界

安全回归只使用合成账号和本地假响应，涵盖门户地址/HTTP 同意、网络绑定失败、重定向和响应限额、JSON 限制、诊断脱敏、GCM 兼容解密和篡改拒绝、损坏凭据保护、账号删除/迁移/并发，以及认证合并和后台终态。

实际执行结果和无法验证的项目见 `验证记录.md`。构建成功不代表已在校园网络或某个厂商手机上验证自动登录。
